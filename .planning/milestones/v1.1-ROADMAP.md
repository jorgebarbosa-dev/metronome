# Milestone v1.1: Training Modes

**Status:** 🚧 IN PLANNING
**Phases:** 5-6
**Estimated Plans:** 5-7
**Target Start:** 2026-05-01

## Overview

O milestone v1.1 do Metrônomo Web adiciona modos de treino avançados para prática estruturada: aumento automático de BPM, compassos de contagem inicial, modo de silêncio intermitente, e uma interface de tela cheia limpa otimizada para ensaios e performance.

## Phases

### Phase 5: Training Engine

**Goal**: Modos de treino avançados para prática estruturada
**Depends on**: Phase 4 (PWA & Polish)
**Plans**: 3-4 plans estimated

Planned requirements:
- TRAIN-01: Auto-BPM increase mode
- TRAIN-02: Count-in mode (1-8 bars)
- TRAIN-03: Silence mode (play N, silence N)
- TRAIN-04: Auto-BPM decrease mode
- TRAIN-05: Silence mode with fade transitions
- TRAIN-06: Training session bar counter and timer
- TRAIN-07: Training configuration persistence
- TRAIN-08: Combined training modes

**Details:**
- User can configure automatic BPM increase (start BPM, increment, interval in bars, target BPM)
- Count-in plays configurable number of bars before main pattern starts
- Silence mode alternates between playing and silent bars
- Multiple training modes can be active simultaneously
- Training progress is tracked and displayed (bar counter, current/target BPM)
- All training configurations persist in browser storage

---

### Phase 6: Training UI & Fullscreen

**Goal**: Interface dedicada para modos de treino e tela cheia limpa
**Depends on**: Phase 5 (Training Engine)
**Plans**: 2-3 plans estimated

Planned requirements:
- UI-01: Training mode controls panel
- UI-02: Training mode status display
- FULL-01: Clean fullscreen mode
- FULL-02: Fullscreen training overlay
- FULL-03: Large visual beat indicator for distance viewing

**Details:**
- Training mode controls are accessible and clearly distinguished
- Active training status visible during playback (progress, BPM changes)
- Clean fullscreen shows only essential info (BPM, time signature, pulse, play)
- Fullscreen training overlay displays bar counter and mode progress
- Large visual beat indicator optimized for distance viewing
- All training UI is keyboard accessible and screen-reader friendly

---

## Milestone Summary

**Key Decisions:**

- Training engine extends existing scheduler (no rewrite needed) — add training state machine alongside audio scheduler
- Training modes are composable (can combine count-in + auto-BPM + silence) — implemented as independent modifiers
- Fullscreen mode is a separate view component (not CSS-only) — allows different layout optimized for distance viewing

**Issues Deferred from v1.0:**

- Setlists / multi-song playlists — requires song management architecture, deferred to v2.0
- Polyrhythms — requires scheduler rewrite for multiple simultaneous rhythms, deferred to v2.0
- Swing adjustment — requires subdivision engine modification, deferred to v2.0
- Rhythmic patterns for odd time signatures — requires pattern editor UI, deferred to v2.0

**Technical Debt to Address:**

- Extend existing scheduler for training modes (no new debt expected)
- Reuse PWA fullscreen capabilities from Phase 4
- Training state management may need new context/hook layer
