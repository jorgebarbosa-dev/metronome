# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-01
**Phases:** 1-4
**Total Plans:** 12

## Overview

O MVP do Metrônomo Web entrega um metrônomo web preciso, responsivo e instalável. Inclui engine de áudio com Web Audio API, interface acessível, subdivisões rítmicas, presets salvos localmente e capacidade PWA completa.

## Phases

### Phase 1: Core Engine

**Goal**: Metrônomo básico funcional com precisão de tempo
**Depends on**: (foundation)
**Plans**: 3 plans

Plans:

- [x] 01-01: Project scaffold + Audio engine with lookahead scheduler
- [x] 01-02: State management with React Context, tap tempo, and persistence
- [x] 01-03: UI components, responsive layout, and accessibility

**Details:**
- User can start/stop metronome and hear consistent clicks at any BPM between 40-240
- Tap tempo calculates BPM accurately within 2 BPM of target
- Time signature changes work correctly (beat 1 is always accented when enabled)
- Volume control affects click loudness in real-time
- Timing remains stable even when switching browser tabs or under CPU load
- Audio starts on first user click without requiring second interaction

## Milestone Summary

**Key Decisions:**

- Web Audio API ao invés de setInterval — Precisão de tempo é o core value; setInterval atrasa
- PWA com offline first — Músicos usam em ensaios e palco onde internet é instável
- localStorage/IndexedDB para dados locais — MVP sem backend; dados persistentes no navegador
- React + TypeScript + Vite — Stack moderna, tipagem ajuda em lógica de áudio complexa
- Lookahead scheduler (25ms/100ms) — Padrão estabelecido para precisão de tempo
- Square wave oscillator for clicks — Som claro e preciso para metrônomo

**Issues Resolved:**

- Precisão de tempo crítica via Web Audio API scheduling
- Compatibilidade cross-browser para PWA (manifest, service worker, icons)
- Persistência de dados sem backend (localStorage + IndexedDB)
- Acessibilidade completa (keyboard, screen readers, ARIA)

**Issues Deferred:**

- v2 features: training modes (auto BPM, silence), setlists, polyrhythms, swing
- Cloud sync / user accounts — MVP local-first
- MIDI / Ableton Link integration — complexidade alta
- Detailed practice statistics — fora do escopo do MVP

**Technical Debt Incurred:**

- Presets são estáticos (usuário não pode modificar sons em runtime)
- Service worker caching usa Workbox padrão (pode precisar fine-tuning para updates)
- Fullscreen API comportamento varia por browser — testado apenas em Chrome/Edge/Safari
