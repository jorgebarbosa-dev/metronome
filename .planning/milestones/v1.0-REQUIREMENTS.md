# Requirements: Metrônomo Web

**Defined:** Thu Apr 30 2026
**Core Value:** A precisão do tempo é inegociável — se o metrônomo não mantém o tempo consistente, nada mais importa.

## v1 Requirements (SHIPPED)

### Metrônomo Básico

- [x] **BASIC-01**: User can start and stop the metronome with a large, prominent button
- [x] **BASIC-02**: User can set BPM between 40 and 240 using numeric input, slider, and +/- buttons
- [x] **BASIC-03**: User can use tap tempo to calculate BPM by tapping a button rhythmically
- [x] **BASIC-04**: User can select time signature (1/4, 2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 8/8)
- [x] **BASIC-05**: User hears accented sound on beat 1 and unaccented sound on other beats
- [x] **BASIC-06**: User can toggle accent on/off
- [x] **BASIC-07**: User can control volume with a slider and mute button
- [x] **BASIC-08**: Volume preference is saved locally for next session

### Áudio e Precisão

- [x] **AUDIO-01**: Metronome maintains consistent timing using Web Audio API (not setInterval)
- [x] **AUDIO-02**: Scheduler uses lookahead pattern to ensure precision even under load
- [x] **AUDIO-03**: Audio context resumes on first user gesture (handles browser autoplay policy)
- [x] **AUDIO-04**: User can choose between at least 3 different click sounds
- [x] **AUDIO-05**: Different sounds for accented beat vs unaccented beats

### Interface e Feedback

- [x] **UI-01**: User sees visual pulse feedback on each beat (circle animation or highlight)
- [x] **UI-02**: User sees current beat number displayed (1, 2, 3, 4...)
- [x] **UI-03**: First beat is visually distinguished from other beats
- [x] **UI-04**: Interface is responsive and works on desktop, tablet, and mobile
- [x] **UI-05**: All controls are usable with keyboard navigation
- [x] **UI-06**: Interface has sufficient color contrast and ARIA labels

### Subdivisões

- [x] **SUBD-01**: User can enable quarter note subdivisions (1 click per beat)
- [x] **SUBD-02**: User can enable eighth note subdivisions (2 clicks per beat)
- [x] **SUBD-03**: User can enable triplet subdivisions (3 clicks per beat)
- [x] **SUBD-04**: User can enable sixteenth note subdivisions (4 clicks per beat)
- [x] **SUBD-05**: Subdivision selection is visually clear in the interface

### Presets e Persistência

- [x] **PRES-01**: User can save current settings (BPM, time signature, subdivision, sound, volume) as a named preset
- [x] **PRES-02**: User can load a saved preset
- [x] **PRES-03**: User can delete a saved preset
- [x] **PRES-04**: Presets are persisted in browser storage
- [x] **PRES-05**: Last used settings are restored on next visit

### PWA e Offline

- [x] **PWA-01**: App is installable as PWA on mobile and desktop
- [x] **PWA-02**: App works completely offline after first load
- [x] **PWA-03**: App displays correctly in fullscreen mode

## v2 Requirements (DEFERRED)

### Modos de Treino

- **TRAIN-01**: User can set automatic BPM increase (start BPM, increment, every N bars, target BPM)
- **TRAIN-02**: User can enable silence mode (play N bars, silence N bars)
- **TRAIN-03**: User can set count-in before starting (1-2 bars)

### Setlists

- **SET-01**: User can create setlists with multiple songs
- **SET-02**: Each song stores BPM, time signature, and subdivision
- **SET-03**: User can reorder songs in setlist
- **SET-04**: User can quickly switch between songs during performance

### Recursos Avançados

- **ADV-01**: User can practice polyrhythms (e.g., 3 against 2, 4 against 3)
- **ADV-02**: User can adjust swing feel
- **ADV-03**: User can set rhythmic patterns for odd time signatures (e.g., 7/8 = 2+2+3)

### Tela Cheia e UX

- **FULL-01**: User can enter clean fullscreen mode showing only BPM, time signature, pulse, and play button

## Out of Scope

| Feature | Reason |
|---------|--------|
| Cloud sync / user accounts | MVP is local-first. Cloud adds complexity and privacy concerns. |
| MIDI / Ableton Link integration | Very advanced feature for small professional audience. High complexity. |
| Exercise library | Content creation is different product. Can be added later. |
| Detailed practice statistics | Analytics interesting but not core to metronome functionality. |
| Video tutorials / lessons | Out of product scope. |
| Social features / sharing | Metronome is personal tool, not social platform. |
