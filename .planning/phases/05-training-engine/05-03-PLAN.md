## Integration Points

### 1. Scheduler Start Integration

Currently, `MetronomeContext` starts the scheduler like this:
```typescript
scheduler.start(
  state.bpm,
  state.timeSignature,
  state.accentEnabled,
  state.volume,
  soundConfig,
  state.subdivision
);
```

Needs to become:
```typescript
scheduler.start(
  state.bpm,
  state.timeSignature,
  state.accentEnabled,
  state.volume,
  soundConfig,
  state.subdivision,
  training.config, // training config
  (barNumber, schedTrainingState) => {
    // Update React state
    setTrainingSession({
      isActive: true,
      currentBar: barNumber,
      phase: schedTrainingState.isCountIn ? 'count-in' : 'playing',
      countInBarsRemaining: schedTrainingState.countInBarsRemaining,
      silenceIsMuted: schedTrainingState.silenceIsMuted,
      silenceBarsRemaining: schedTrainingState.silenceBarsRemaining,
      autoBpmCurrentValue: schedTrainingState.autoBpmCurrentValue,
      autoBpmBarsUntilNext: schedTrainingState.autoBpmBarsUntilNext,
    });
  }
);
```

### 2. Preset Integration

Current preset creation in `PresetManager` or `usePresets` doesn't include training config. Need to:
- Include `trainingConfig` when creating presets
- Restore `trainingConfig` when loading presets

### 3. Session Reset

When playback stops, training session state should reset:
```typescript
setTrainingSession(createInitialSessionState(training.config));
```

When playback starts, training session state should initialize fresh:
```typescript
setTrainingSession(createInitialSessionState(training.config));
```

### 4. App.tsx Integration

`App.tsx` needs access to training state for UI components (Phase 6). Already available via `useMetronome()` but need to verify destructuring works.

## IndexedDB Migration

Current preset storage uses `DB_VERSION = 1`. Adding `trainingConfig` field doesn't strictly require migration (IndexedDB is schemaless), but best practice is to increment version:

```typescript
const DB_VERSION = 2;

request.onupgradeneeded = (event) => {
  const db = (event.target as IDBOpenDBRequest).result;
  if (!db.objectStoreNames.contains(STORE_NAME)) {
    const store = db.createObjectStore(STORE_NAME, { keyPath: 'id' });
    store.createIndex('name', 'name', { unique: false });
  }
  // Migration from v1 to v2: no structural changes needed
  // Existing objects will simply have undefined trainingConfig
};
```
