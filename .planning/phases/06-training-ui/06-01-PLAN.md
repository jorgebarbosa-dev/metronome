## Existing Training State (from MetronomeContext)

```typescript
// Available via useMetronome():
interface MetronomeContextType {
  trainingConfig: TrainingConfig;        // Current configuration
  trainingSession: TrainingSessionState; // Live session state from scheduler
  trainingActions: {
    updateAutoBpm: (partial: Partial<AutoBpmConfig>) => void;
    updateSilence: (partial: Partial<SilenceConfig>) => void;
    updateCountIn: (partial: Partial<CountInConfig>) => void;
    resetTraining: () => void;
  };
}
```

## TrainingConfig Shape

```typescript
interface TrainingConfig {
  autoBpm: { enabled: boolean; startBpm: number; targetBpm: number; increment: number; everyNBars: number };
  silence: { enabled: boolean; playBars: number; silenceBars: number };
  countIn: { enabled: boolean; measures: number };
}
```

## TrainingSessionState Shape

```typescript
interface TrainingSessionState {
  isActive: boolean;
  currentBar: number;
  phase: 'count-in' | 'playing';
  countInBarsRemaining: number;
  silenceIsMuted: boolean;
  silenceBarsRemaining: number;
  autoBpmCurrentValue: number;
  autoBpmBarsUntilNext: number;
}
```

## UI Patterns to Follow

**Toggle switch:**
```tsx
<button
  role="switch"
  aria-checked={enabled}
  onClick={() => update({ enabled: !enabled })}
  className={`relative w-11 h-6 rounded-full transition-colors ${enabled ? 'bg-blue-600' : 'bg-gray-200 dark:bg-gray-700'}`}
>
  <span className={`absolute top-0.5 left-0.5 w-5 h-5 bg-white rounded-full transition-transform ${enabled ? 'translate-x-5' : 'translate-x-0'}`} />
</button>
```

**Number input with label:**
```tsx
<div className="flex flex-col gap-1">
  <label htmlFor="input-id" className="text-sm font-medium text-gray-700 dark:text-gray-300">Label</label>
  <input
    id="input-id"
    type="number"
    min={40}
    max={240}
    value={value}
    onChange={(e) => update({ field: clamp(Number(e.target.value), min, max) })}
    className="w-20 px-2 py-1 text-sm border rounded-md dark:bg-gray-800 dark:border-gray-600"
  />
</div>
```

**Button with icon:**
```tsx
<button
  onClick={...}
  aria-label="..."
  aria-expanded={isOpen}
  className="flex items-center gap-1.5 px-3 py-1.5 text-sm font-medium text-gray-700 dark:text-gray-300 bg-gray-100 hover:bg-gray-200 dark:bg-gray-800 dark:hover:bg-gray-700 rounded-lg transition-colors focus-visible:ring-2 focus-visible:ring-blue-500 focus-visible:ring-offset-2"
>
  <Icon className="w-4 h-4" aria-hidden="true" />
  <span>Label</span>
</button>
```

- Panel open/close is local state only (useState in App.tsx or TrainingPanel)
- TrainingStatus must use live region for screen reader announcements
- Keyboard navigation: Tab moves through controls, Enter/Space toggles switches
