## Existing BeatIndicators Pattern
```tsx
export function BeatIndicators() {
  const { currentBeat, state } = useMetronome();
  const { timeSignature } = state;
  const totalBeats = timeSignature.beats;

  return (
    <div className="flex items-center justify-center gap-2" role="status" aria-label={`Beat ${currentBeat} of ${totalBeats}`}>
      {Array.from({ length: totalBeats }, (_, i) => {
        const beatNumber = i + 1;
        const isActive = beatNumber === currentBeat;
        const isBeatOne = beatNumber === 1;
        return (
          <div key={beatNumber} className={`w-4 h-4 rounded-full transition-colors duration-150 ${isActive ? isBeatOne ? 'bg-red-500' : 'bg-blue-600' : 'bg-gray-300 dark:bg-gray-600'}`} aria-hidden="true" />
        );
      })}
    </div>
  );
}
```

## Existing Context Pattern
- `useMetronome()` returns `{ state, currentBeat, dispatch, audioEngine }`
- `state` includes: bpm, isPlaying, timeSignature, accentEnabled, volume, selectedSound, subdivision
- Actions dispatched via `dispatch({ type: '...', payload: ... })`
