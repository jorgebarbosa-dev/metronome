**From src/types/metronome.ts:**
```typescript
export interface SoundConfig {
  accentFrequency: number;
  normalFrequency: number;
  waveType: OscillatorType;
  attackTime: number;
  decayTime: number;
}

export const DEFAULT_SOUND_CONFIG: SoundConfig = {
  accentFrequency: 1000,
  normalFrequency: 800,
  waveType: 'square',
  attackTime: 0.001,
  decayTime: 0.05,
};
```

**From src/audio/sounds.ts:**
- `playClick()` accepts `SoundConfig`, `isAccent`, `volume`, `time`
- Uses `OscillatorNode` with `config.waveType`
- Frequency selected via `isAccent ? config.accentFrequency : config.normalFrequency`
- Envelope: setValueAtTime(0) → linearRampToValueAtTime(maxVolume, time+attack) → exponentialRampToValueAtTime(0.001, time+attack+decay)

- D-02: 3 sounds: Classic (square, sharp), Wood (softer, rounder), Click (short, crisp)
- D-03: Accent via frequency difference (higher = accented)
- D-04: SoundConfig extensible for multiple presets
