       ```typescript
       {
         bpm: number | null;        // Current calculated BPM
         tap: () => void;           // Call on each tap
         reset: () => void;         // Manual reset
         isListening: boolean;       // True if within 2s window
       }
       ```
    
    2. Implementation:
       - Maintain an array of the last tap timestamps (Date.now() or performance.now())
       - On `tap()`:
         a. Record current timestamp
         b. Remove taps older than 2 seconds (per D-13)
         c. If fewer than 2 taps: set `bpm` to null, `isListening` to true
         d. If 2+ taps: calculate intervals between consecutive taps, average them, convert to BPM via `60000 / avgInterval`
         e. If 5+ taps (per D-11): use only the last 5 taps for the average
         f. Set `bpm` to calculated value (round to nearest integer)
         g. Set `isListening` to true
         h. Start/reset a 2-second timeout: when it fires, set `isListening` to false and clear tap history
       - On `reset()`: clear all taps, set `bpm` to null, `isListening` to false
       - Use `useRef` for the timeout ID to avoid stale closures
       - Use `useCallback` for `tap` and `reset` functions
    
    3. Behavior:
       - First tap: starts listening, no BPM yet
       - Second tap: shows first BPM estimate (may be inaccurate)
       - Third+ taps: BPM becomes more stable
       - After 2s silence: stops listening, clears history
  </action>
